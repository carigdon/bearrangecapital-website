# bearrangecapital.com

Static landing page for Bear Range Capital, hosted on Vercel.

- `index.html` – the homepage
- `investors.html` – investor login placeholder (submits to `invalid.html`)
- `invalid.html` – "Invalid username or password" page
- `images/` – logo and favicon

There is no build step: Vercel serves these files as they are. Every push to `main` deploys to production.
